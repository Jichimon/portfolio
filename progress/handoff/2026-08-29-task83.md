## What already exists — read this before writing anything

`scripts/guards/lib/path-boundary.mjs:175`, inside the `'all'`-mode loop:

```js
for (const arg of args) {
  if (arg.startsWith('-')) continue;
  flag(arg, head);
}
```

This already denies a target followed by a flag correctly — `startsWith` runs per-argument, not
only on the last one — but nothing in `path-boundary.test.mjs` exercises that shape. Found by
reading `TASK 61`'s own mutation survivors: two mutants at the **identical** logic `TASK 61`
introduced (`:185`, for its new `inplace`/`dest` handling) survived — `arg.startsWith('-')`
mutated to `false` and to `arg.endsWith('-')` — and the same untested shape exists one level
up, in the loop above, which `TASK 61` did not touch.

## The test to write

A red battery (mutation-proven, not failing-today — the code already works, the *test* is what
is missing) planting a trailing flag after an `'all'`-mode target:

- `rm -rf resources/ -v` → still denied
- `mv resources/a.md /tmp/a.md -v` → still denied

Each assertion must **fail** when `arg.startsWith('-')` is neutered to `arg.endsWith('-')` or to
the literal `false` — that is `TASK 61`'s own two surviving mutants, reproduced deliberately to
prove the new test kills them.
