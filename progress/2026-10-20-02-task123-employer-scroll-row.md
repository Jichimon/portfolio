## Decisions

- **The scrollability expectation is derived from the rendered geometry, never from a width roster** (`P-13`): the assertion reads the cards' own edges to decide whether the strip *must* scroll, so a role count that fits asserts no scroll and one that overflows asserts it.
- **The settle is asserted with a real wheel gesture**, not a programmatic snap read — the settle is what the visitor observes, and the stride comes from the rendered cards, not from a hardcoded width.
- **The spec id never appears inside `site/**`** — the citation runs from the document to the code (`S-08`). Corrected after the guard caught the first draft, not before it shipped.
