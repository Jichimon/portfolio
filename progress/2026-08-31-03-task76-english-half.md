## Decisions

- **The deliverable is two staging folders, not an edit.** `H-02` denies `resources/**` to every agent at rung 1, by a `deny` rule in `.claude/settings.json` and by the `resources-readonly` guard. Both read this session. The author asked for the files to be modified directly; that is not available, and the nearest thing that is, is a complete replacement file per object plus a packet enumerating every change. `TASK 20` and `TASK 26` set the precedent.
- **Scale figures, settled by the author before any English was written.** Total users of the bank app reads as *millions of people*; active users reads as *more than a million active users*. The QR module keeps *100,000 users in the first three months*. NICE keeps *millions of users* and is a different system. Asked rather than assumed (`C-01`, `INC-09`).
- **The em-dash leaves both locales.** Not a style preference imported from outside: the author removed it from two subtitles in `7c5014c`, and the Spanish rewrite had already dropped most of the rest (81 English lines against 24 Spanish at session start; both now zero). Replacement chosen per context, never mechanically. The en-dash `–` in ranges stays.
- **`profile-README.md` is in scope** although it is not a `*.en.md`: it repeated the stale figure, and `C-03` requires a correction to propagate to every derived page in the same change.
- **Every file except `about.en.md` was generated by exact string replacement, not retyped.** A script read each original, applied the listed replacements, refused to run unless every pattern matched exactly once, and asserted zero em-dashes in the result. On a 19-file content change the dominant risk is a silent transcription slip in a paragraph nobody re-reads, and this removes that risk rather than mitigating it. `about.en.md` is genuinely new prose and was written by hand.
- **One Spanish sentence was left untranslated on purpose.** `multi-tenant-biometric-attendance.es.md` gained *"un enfoque vertical ambicioso en una tecnología que te seduce con slices horizontales"*, which reads as unfinished. Rendering it would have meant inventing the missing half (`C-01`), so it became `TASK 104` question 3 instead.
